## What Is This Project?

QubitShield is an **interactive scientific application** that investigates how a
**three-qubit bit-flip repetition code** protects a logical qubit against independent
bit-flip errors, and quantifies the improvement over an unprotected qubit.

The core research question:

> *How effectively can a three-qubit quantum bit-flip repetition code protect an encoded qubit against independent bit-flip errors, and how does its logical failure probability compare with that of an unencoded qubit?*

---

## Why It Matters

Quantum processors are error-prone. Quantum error correction (QEC) is the
fundamental technology that enables reliable quantum computation. The three-qubit
repetition code is the simplest correcting code and illustrates all core QEC concepts:
encoding, stabilizer syndrome extraction, minimum-weight decoding, and logical failure analysis.

This project demonstrates:
- Genuine implementation of quantum circuits in Qiskit (not simulated results)
- Mathematical derivation and simulation-validated failure probability analysis
- Understanding of the gap between idealized models and fault-tolerant computation
- Scientific software practices: modular architecture, type hints, automated tests, documentation

## Quantum Concepts Demonstrated

### Encoding
A logical qubit $|\psi\rangle = \alpha|0\rangle + \beta|1\rangle$ is encoded as:

$$|\psi_L\rangle = \alpha|000\rangle + \beta|111\rangle$$

using two CNOT gates. This is **not** classical copying — it exploits quantum entanglement.

### Syndrome Extraction
Two ancilla qubits measure parity checks $Z_0Z_1$ and $Z_1Z_2$:

| Syndrome $(s_{01}, s_{12})$ | Error detected | Recovery |
|:---:|:---:|:---:|
| $(0, 0)$ | No error | None |
| $(1, 0)$ | Bit-flip on qubit 0 | Apply $X_0$ |
| $(1, 1)$ | Bit-flip on qubit 1 | Apply $X_1$ |
| $(0, 1)$ | Bit-flip on qubit 2 | Apply $X_2$ |

### Logical Failure Probability

$$P_{\text{logical}}(p) = 3p^2(1-p) + p^3 = 3p^2 - 2p^3$$

The code outperforms the unencoded qubit ($P = p$) for $p < 0.5$.

At p=0.1, the repetition code reduces logical failure probability by **72%** relative to an unencoded qubit.

## Assumptions and Limitations

This simulation uses an **idealized error model**:

- Only independent, identically distributed bit-flip (X) errors on data qubits
- No errors in encoding gates, CNOT gates, ancilla preparation, or measurement
- No phase-flip errors, depolarizing noise, or correlated errors
- No fault-tolerant circuit design

**The code does not correct phase-flip (Z) errors.** The Shor 9-qubit code or CSS codes are needed for full error correction.

**Results are from classical software simulation.** They were not obtained from physical quantum hardware. Qiskit Aer replicates the mathematical behavior of quantum circuits but cannot model all physical noise sources.

See [`docs/limitations.md`](docs/limitations.md) for a full discussion.
