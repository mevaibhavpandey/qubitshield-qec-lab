# Mathematical Background — QubitShield

> This document provides a rigorous derivation of the quantum states, stabilizer
> formalism, syndrome table, and logical failure probability formula used in QubitShield.

---

## 1. Quantum State Representation

A single-qubit quantum state is a vector in a two-dimensional complex Hilbert space ℂ²:

$$|\psi\rangle = \alpha|0\rangle + \beta|1\rangle, \quad \alpha, \beta \in \mathbb{C}, \quad |\alpha|^2 + |\beta|^2 = 1$$

The computational basis vectors are:

$$|0\rangle = \begin{pmatrix} 1 \\ 0 \end{pmatrix}, \qquad |1\rangle = \begin{pmatrix} 0 \\ 1 \end{pmatrix}$$

The Pauli X (bit-flip) operator acts as:

$$X = \begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix}, \quad X|0\rangle = |1\rangle, \quad X|1\rangle = |0\rangle$$

The Pauli Z (phase-flip) operator acts as:

$$Z = \begin{pmatrix} 1 & 0 \\ 0 & -1 \end{pmatrix}, \quad Z|0\rangle = |0\rangle, \quad Z|1\rangle = -|1\rangle$$

---

## 2. Encoding: Three-Qubit Bit-Flip Repetition Code

### 2.1 Codespace

The **code space** of the three-qubit repetition code is the two-dimensional subspace of ℂ⁸ spanned by:

$$|0_L\rangle = |000\rangle, \qquad |1_L\rangle = |111\rangle$$

An arbitrary logical qubit $|\psi\rangle = \alpha|0\rangle + \beta|1\rangle$ is encoded as:

$$|\psi_L\rangle = \alpha|000\rangle + \beta|111\rangle$$

### 2.2 Encoding Circuit

The encoding circuit maps $|\psi\rangle \otimes |00\rangle \to |\psi_L\rangle$:

$$(\alpha|0\rangle + \beta|1\rangle) \otimes |0\rangle \otimes |0\rangle$$

$$\xrightarrow{\text{CNOT}_{01}} \alpha|000\rangle + \beta|110\rangle$$

$$\xrightarrow{\text{CNOT}_{02}} \alpha|000\rangle + \beta|111\rangle = |\psi_L\rangle$$

The CNOT gate maps $|c, t\rangle \to |c, c \oplus t\rangle$ where $\oplus$ is XOR.

### 2.3 No-Cloning Theorem

This is NOT copying. The no-cloning theorem (Wootters & Zurek, 1982) states there is no unitary operation $U$ such that $U|\psi\rangle|0\rangle = |\psi\rangle|\psi\rangle$ for all $|\psi\rangle$. The encoding produces an entangled three-qubit state where the logical information is distributed across all three qubits.

---

## 3. Stabilizer Formalism

### 3.1 Stabilizer Group

The repetition code is a **stabilizer code**. Its stabilizer group is generated by:

$$g_1 = Z_0 \otimes Z_1 \otimes I_2, \qquad g_2 = I_0 \otimes Z_1 \otimes Z_2$$

Abbreviated: $g_1 = Z_0 Z_1$, $g_2 = Z_1 Z_2$.

Both codewords are $+1$ eigenstates of these generators:

$$g_1|000\rangle = (Z|0\rangle)(Z|0\rangle)(I|0\rangle) = |0\rangle|0\rangle|0\rangle = |000\rangle$$
$$g_1|111\rangle = (Z|1\rangle)(Z|1\rangle)(I|1\rangle) = (-|1\rangle)(-|1\rangle)|1\rangle = |111\rangle$$

Similarly for $g_2$. So any state $|\psi_L\rangle = \alpha|000\rangle + \beta|111\rangle$ satisfies $g_i|\psi_L\rangle = |\psi_L\rangle$.

### 3.2 Error Detection via Anticommutation

A Pauli X error on qubit $i$ is detected because $X_i$ anticommutes with stabilizers that contain $Z_i$:

$$g_1 X_0 = Z_0 Z_1 X_0 = -X_0 Z_0 Z_1 = -X_0 g_1$$

More precisely:
- $[g_1, X_0] \neq 0$: $X_0$ anticommutes with $g_1$ (they don't commute)
- $[g_1, X_2] = 0$: $X_2$ commutes with $g_1$ (acting on different qubit)

This anticommutation means that if an $X_0$ error occurs, measuring $g_1$ gives eigenvalue $-1$ instead of $+1$, revealing the error.

## 4. Syndrome Extraction and Measurement

### 4.1 Ancilla-Based Parity Measurement

To measure $g_1 = Z_0 Z_1$ without destroying the logical state:

1. Prepare ancilla in $|0\rangle$
2. Apply CNOT$(q_0 \to \text{anc})$ and CNOT$(q_1 \to \text{anc})$
3. Measure ancilla

The ancilla accumulates the parity: if $q_0 \oplus q_1 = 0$ (same), ancilla = $|0\rangle$; if $q_0 \oplus q_1 = 1$ (different), ancilla = $|1\rangle$.

For the codewords: $|000\rangle$ has parity $(0,0)$ and $|111\rangle$ has parity $(0,0)$, so no syndrome in either case. A single $X_0$ error changes this.

### 4.2 Full Syndrome Table Derivation

Define $e_i \in \{0,1\}$ as the indicator for an X error on qubit $i$.

$$s_{01} = e_0 \oplus e_1, \qquad s_{12} = e_1 \oplus e_2$$

| Error | $e_0$ | $e_1$ | $e_2$ | $s_{01} = e_0 \oplus e_1$ | $s_{12} = e_1 \oplus e_2$ |
|:---:|:---:|:---:|:---:|:---:|:---:|
| None | 0 | 0 | 0 | 0 | 0 |
| $X_0$ | 1 | 0 | 0 | 1 | 0 |
| $X_1$ | 0 | 1 | 0 | 1 | 1 |
| $X_2$ | 0 | 0 | 1 | 0 | 1 |
| $X_0 X_1$ | 1 | 1 | 0 | 0 | 1 |
| $X_0 X_2$ | 1 | 0 | 1 | 1 | 1 |
| $X_1 X_2$ | 0 | 1 | 1 | 1 | 0 |
| $X_0 X_1 X_2$ | 1 | 1 | 1 | 0 | 0 |

The four syndrome patterns for single errors are **unique and distinguishable**. But two-qubit error syndromes overlap with single-qubit error syndromes — the code cannot distinguish them.

---

## 5. Recovery and Logical Operators

### 5.1 Minimum-Weight Decoder

The decoder applies the correction with minimum weight (fewest X gates) consistent with the observed syndrome. For single-error cases, this uniquely identifies the error qubit.

### 5.2 Logical Operators

The logical Pauli operators for this code are:

$$\bar{X} = X_0 X_1 X_2, \qquad \bar{Z} = Z_0 (\text{or } Z_1 \text{ or } Z_2)$$

A logical failure occurs when the net error (applied error + decoder correction) equals a logical operator $\bar{X}$, $\bar{Z}$, or $\bar{Y}$.

For bit-flip errors only, a logical failure occurs when the net number of $X$ errors on data qubits is **odd** after correction.

---

## 6. Logical Failure Probability

### 6.1 Assumptions

- Each data qubit independently experiences an $X$ error with probability $p$.
- Encoding, syndrome measurement, and recovery are performed perfectly (no gate errors).
- The channel is the independent identically distributed (i.i.d.) bit-flip channel.

### 6.2 Derivation

The code corrects all single-qubit errors. It fails when **two or more** errors occur.

**Two-qubit errors:** There are $\binom{3}{2} = 3$ patterns. Each has probability $p^2(1-p)$.

**Three-qubit errors:** There is $\binom{3}{3} = 1$ pattern. It has probability $p^3$.

$$P_{\text{logical}}(p) = 3p^2(1-p) + p^3 = 3p^2 - 3p^3 + p^3 = 3p^2 - 2p^3$$

### 6.3 Break-Even Analysis

Setting $P_{\text{logical}} = P_{\text{unencoded}} = p$:

$$3p^2 - 2p^3 = p$$
$$3p - 2p^2 = 1 \quad \text{(dividing by }p \text{ for }p>0)$$
$$2p^2 - 3p + 1 = 0$$
$$(2p-1)(p-1) = 0$$

Solutions: $p = 0.5$ and $p = 1$. For $0 < p < 0.5$, the code provides a benefit.

### 6.4 Asymptotic Behavior

For small $p$: $P_{\text{logical}} \approx 3p^2 \ll p$ — quadratic suppression.

For $p$ near 0.5: The code provides no improvement and eventually makes things worse.

At $p = 1$ (all qubits always flip): All three qubits flip → syndrome $(0,0)$ → no correction applied → logical $|0\rangle$ becomes $|111\rangle = |1_L\rangle$ → failure probability 1.

---

## 7. What the Code Cannot Correct

### 7.1 Phase Errors

The code does not protect against phase-flip ($Z$) errors. The codewords $|000\rangle$ and $|111\rangle$ are both $+1$ eigenstates of $Z_0$, $Z_1$, $Z_2$, so a $Z$ error does not change the measurement outcomes of $g_1$ or $g_2$. However, $Z_0|+_L\rangle = Z_0(|000\rangle + |111\rangle)/\sqrt{2} = (|000\rangle - |111\rangle)/\sqrt{2} = |-_L\rangle$, which is a logical $\bar{Z}$ error.

To correct both $X$ and $Z$ errors simultaneously, codes like the Shor 9-qubit code or CSS codes are required.

### 7.2 Gate Errors

The analysis assumes ideal (error-free) encoding gates, CNOT gates, ancilla preparation, and measurement. In practice, each operation introduces additional error probability, requiring fault-tolerant circuit design.
